# 15分ワークショップ計画シート

講師・ファシリテーターが、自分のテーマに合わせて書き込む空欄の計画シートです。まず完成済みファイルを開いてから、必要な部分を編集できます。15分と3分＋9分＋3分の配分は変更できる進行例です。

## 先にファイルを開く

- [HTML・Markdownをまとめて保存する（ZIP）](https://github.com/kumiromiscythespec/workshop-planning-worksheet/releases/download/v1.0.0/workshop-planning-template.zip)
- [編集用Markdownを保存する](https://github.com/kumiromiscythespec/workshop-planning-worksheet/releases/download/v1.0.0/workshop-planning-worksheet.md)
- [印刷用の下書きHTMLを保存する](https://github.com/kumiromiscythespec/workshop-planning-worksheet/releases/download/v1.0.0/workshop-planning-worksheet.html)

ZIPを展開したら、README.txtを読み、files内のMarkdownまたはHTMLを選んでください。manifest.jsonは内容物の一覧です。

~~~text
README.txt
manifest.json
files/workshop-planning-worksheet.html
files/workshop-planning-worksheet.md
~~~

1. Markdownをテキストエディターで開き、角括弧内の問いを自分のテーマに書き換えるか、計画を書き込みます。
2. HTMLは印刷用の下書きです。使う前に、ご自身の環境で表示・改ページ・文字切れを確認してください。
3. MarkdownとHTMLは別々の保存物です。一方を編集しても、もう一方は自動更新されません。

氏名などの個人情報は書き込まず、対象者像・準備・進め方に必要な内容だけを記入してください。

## 入っている問い

3セクション、6つの問い、計18行の回答欄があります。

- 対象と取り組む作業：対象者と前提、観察できる作業を一つ
- 準備と進行：材料と準備、導入と実践
- 確認と振り返り：確認と振り返り、終了後の進行役メモ

3分＋9分＋3分は変更できる進行例です。実施前に、問い・所要時間・使う資料を自分のワークショップに合わせて確認してください。
